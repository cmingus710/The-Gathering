This is a catalog of titles, topic labels, and source links only. Prayer bodies, excerpts, images, and author claims are not included.
Categories are those listed by the source; this is not a claim that the source taxonomy is complete or that all prayers on the site were found. Categories can overlap. Some source category counts may differ from the links currently listed.

IMPORT
JSON categories are arrays. CSV categories contain JSON arrays suitable for a PostgreSQL jsonb column. is_published defaults to false for review.
Use the included SQL to create a separate link-catalog table, then import prayers.csv into that table using Supabase Table Editor. Do not import into an existing table without mapping its fields first.
