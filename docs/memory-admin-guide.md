# Memory verse administration (Phase 9)

For memory verse editors and publishers (**Administration → Memory verses**, `/admin/memory`) and for group leaders whose group a publisher authorized (**Memory verses → My group's memory verses**, `/memory/lead`).

## Who can do what

| | Editor (`memory.manage`) | Publisher (`memory.publish`) | Authorized group leader | Super administrator |
| --- | --- | --- | --- | --- |
| Draft church and group collections, add and edit verses, preview | Yes | Yes | Their authorized groups only | Yes (implicitly) |
| Publish, schedule, archive, restore, change published collections, update verse text | No | Yes | Their authorized groups only | Yes |
| Duplicate; delete unused drafts | Yes | Yes | Their groups only | Yes |
| Authorize a group's leaders | No | Yes | No | Yes |
| Run group challenges | No | Any group | Their authorized groups only | Yes |
| See anyone's practice, accuracy, schedule, badges, settings, or personal collections | **No** | **No** | **No** | **No** |

Roles: **Memory verse editor** and **Memory verse publisher** (Administration → Members). Group leaders hold no capability: a publisher authorizes a group under *Group leaders* on `/admin/memory`, which lets that group's *active leaders* (Phase 5 leadership) manage collections whose audience is that group, and nothing else: not membership, giving, care, prayer, journals, other groups, or church-wide collections. Revoking it ends their access immediately. Every change is in the audit log (field names and states only, never content or results).

## Scripture source

Verses come only from the church's approved Bible versions (Phase 8, **Administration → Bible sources**). A collection uses one version for all its verses. Only versions whose text is stored here can be memorized: scoring needs the exact wording on the server, and API translations may not be stored. Today that's the public-domain WEB (and ASV once imported).

You choose a passage by reference (book, chapter, verses; up to 30 verses and 900 words). The exact text is captured as a passage version with its translation, text version, and a content hash. You never type or edit scripture. Titles, notes, and hints are editorial and are always shown apart from the verse.

Suitability notes appear under each verse: longer than 80 words (typing, word order, and missing words then use one part at a time), the number of shorter parts used by the kids presentation, very short passages, verses the version omits (left out of the practice text), and source text that has changed since the verse was added.

Long passages are split automatically into parts of up to 32 words (16 for kids) at verse boundaries, or at clause punctuation inside a long verse. Parts are ranges of the text; the words never change.

## Collections

1. **New collection**: title, description, who it's for (all approved members, or one group), Bible version, kind (*collection* or *multiweek sequence*), optional practice goal ("Learn one verse a week") and suggested sessions per week (a suggestion only), and order.
2. **Add verses** by reference, with optional assignment dates (*Assigned from / until*, up to 13 weeks), title, hint, and note.
3. **Sequence**: *Fill in dates* assigns verse 1 from a start date for 1 week (or 2 weeks, 1 day, 30 days), verse 2 the next period, and so on. Adjust any verse afterwards.
4. **Preview activities**: every activity at every difficulty, for the whole passage or any part, generated by the same server functions members use (choices and shuffles change each time; hidden answers shown to you in brackets). Nothing is recorded.
5. **Publish now**, or **Schedule** for a date and time in the collection's time zone. A scheduled collection appears by itself at that time (no job needed); *Back to draft* cancels it.
6. **Cover image**: PNG, JPEG, or WebP, converted to WebP and stored in the private `memory` bucket; members see it through short-lived links only while they can see the collection.

The **current memory verse** (Memory home, the home card, reminders) is any verse whose assignment window includes today in the church's time zone, in a collection the member can see.

**Members may practice in their own Bible version** (checkbox): off by default, which keeps the collection's version required (how every existing collection works). On, each member may add an assigned verse in another stored version, or change it later; the collection, its verses, and other members are never affected. A published collection can turn it on but not off (members may already be practicing in their own version); duplicate the collection to require one version again. Group challenge totals count practice in any version only when this is on, and each practice activity counts once.

### After publishing

- Presentation changes (title, description, goal, order, cover, verse titles, notes, hints, dates) need a publisher; audience, Bible version, and kind are fixed. *Duplicate* to make a new version (a new draft captured from the source's current text; history stays with the original).
- **Reordering, renaming, or archiving never touches practice history.** Verses keep stable ids.
- **Removing a verse** deletes it only from an unpublished draft nobody practiced; otherwise it's retired (hidden, kept for members' history).
- **Archive** hides the collection from browsing. Members keep their verses and history. *Restore* brings it back.
- **Delete** is only for drafts that were never published and that nobody practiced from.

### When the Bible text changes

If a reviewed re-import changes the wording of a verse (Phase 8), the verse shows *The Bible source's text for this reference has changed*. **Use the updated text** (publishers) points it at the new passage version with an explanation members will read. Members' practice of the earlier wording stays with the earlier version, and each member decides when to switch (switching starts fresh). Nothing switches silently, and translations are never changed.

## Group challenges

Optional, adults only, built on group membership. **New group challenge**: group, a published collection the group can see (church-wide or that group's), dates (up to 120 days), a shared goal (practice activities completed together), and how many people must share before totals appear (at least 3, default 5).

Members join only after reading what joining shares. Organizers see exactly what members see: a total rounded down to 5, counted through yesterday, shown only above the threshold. No names, counts per person, accuracy, or rankings exist anywhere. After creation only the title, description, goal, and a later end date can change; **End now** or **Cancel** stop it. Milestones (25/50/75/100%) are announced once to sharing participants who switched challenge reminders on. See [memory-privacy.md](memory-privacy.md).

Family and youth challenges wait for Phase 10's verified guardian permissions.
